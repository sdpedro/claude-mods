# claude-mods

Mods para o Claude Code e o Claude Desktop.

| Mod | O que faz |
| --- | --- |
| [usage-band](plugins/usage-band) | Mostra o consumo do limite de 5h e do semanal numa faixa acima da caixa de mensagem |

## Instalar

```
/plugin marketplace add sdpedro/claude-mods
/plugin install usage-band@sdpedro
```
